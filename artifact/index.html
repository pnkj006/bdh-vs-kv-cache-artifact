Hebbian vs. KV Bloat

Transformer inference memory grows linearly and without bound with context length because it caches every past token's key/value vectors, while BDH's working memory lives in a fixed-size synaptic state updated in place by a local, bounded Hebbian-style rule — trading unbounded storage for a bounded-but-lossy compressed memory.
